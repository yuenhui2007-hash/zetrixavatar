# LearnAI — AI-Powered Tutor & Personalized Learning Platform

A demo landing page showcasing the LearnAI concept — an AI-powered education platform vision. This is not a live product.

## Features

- Personalized AI tutoring & study planning
- AI-generated notes, flashcards & workbooks
- Automated homework & exam marking
- Hyper-personalized learning materials
- Parent, teacher & student dashboards
- Subscription & print-on-demand workbook models

## Live Demo

Visit: [yuenhui2007-hash.github.io/LearnAi](https://yuenhui2007-hash.github.io/LearnAi) — demo/concept only

## Tech Stack

- HTML5
- CSS3 (responsive, no frameworks)
- Vanilla JavaScript
