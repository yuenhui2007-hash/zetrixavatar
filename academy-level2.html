Module 1: Dashboard & Chat Interface

Dashboard Overview

The Zetrix AI Dashboard is your central hub. It provides:

  • Quick Access: Recent conversations, favourite prompts, and pinned documents
  • Usage Analytics: Track queries, tokens used, and time saved
  • Team Workspace: Shared prompts and knowledge bases for departments
  • Settings: Configure AI behaviour, memory, and integrations

Chat Best Practices

  • Thread context: AI remembers the current conversation thread
  • Regenerate: If an answer is poor, ask AI to try again with tweaks
  • Follow-up questions: Drill deeper: "Explain step 3 in more detail"
  • System prompts: Set persona at thread start: "You are a senior financial analyst"

🎯 Interactive Walkthrough

Task: Start a new chat and use this opening prompt:

"You are an expert marketing strategist. I need to create a 30-day social media campaign for a new fitness app targeting professionals aged 25-40. Structure your response as: objectives, platforms, content calendar, KPIs."

Module 2: File Uploads & Document Analysis

Supported File Types

  • PDFs: Extract text, summarise, answer questions
  • Excel/CSV: Analyse data, create charts, find anomalies
  • Word docs: Review, rewrite, translate
  • Images: OCR text extraction, description, analysis
  • Code files: Review, debug, explain

Document Analysis Techniques

  • Summarise: "Summarise this 50-page report in 5 bullet points"
  • Extract: "List all action items and deadlines from this meeting minutes"
  • Compare: "Compare contract v1 and v2 — highlight all changes"
  • Q&A: "Based on this policy document, what is the leave entitlement?"

Module 3: AI Memory

How AI Memory Works

Zetrix AI Memory allows the system to remember preferences, facts, and context across sessions:

  • User Profile: Name, role, department, writing style preferences
  • Project Context: Active projects, deadlines, stakeholders
  • Knowledge Base: Company SOPs, brand guidelines, product info
  • Conversation History: Reference past discussions

Memory Commands

  • "Remember that I work in the Finance department and prefer concise bullet points"
  • "Add to my knowledge base: Our company colours are navy blue and gold"
  • "What did we discuss about the Q3 budget last week?"
  • "Forget my previous preference for formal tone"

1. Telegram Integration

Purpose: Send and receive messages through a Telegram bot. Allow users to chat with your Avatar Claw from Telegram and receive alerts.

How to Connect

  1. Open Telegram and search for @BotFather (verify it is the official account).
  2. Send /newbot, then enter your bot name and username (must end in bot).
  3. Copy the Bot Token provided by BotFather.
  4. In your Avatar Claw, go to Integrations → Telegram → Manage.
  5. Paste the Bot Token and save.
  6. Restart the gateway to load the new configuration.
  7. Open your bot in Telegram and send /start to activate it.

What You Can Do

  • Chat with your AI agent directly
  • Receive push notifications
  • Automate replies in one-on-one or group chats
  • Use requireMention to control group behaviour
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "YOUR_BOT_TOKEN",
      "dmPolicy": "pairing",
      "groups": { "*": { "requireMention": true } }
    }
  }
}

2. Gmail Integration

Purpose: Read emails, draft replies, send messages, and organise your Gmail inbox through your AI agent.

How to Connect

  1. In your Avatar Claw, go to Integrations → Gmail → Connect.
  2. Sign in with your Google account.
  3. Grant the requested Gmail permissions (read, send, manage labels).
  4. Wait until the status changes to Connected.

Permissions Requested

  • Read emails
  • Send emails
  • Manage labels
  • Access your mailbox

What You Can Do

  • "Summarise today's emails."
  • "Reply to John's message."
  • "Draft an email to the marketing team."
  • "Find invoices from last month."
  • "Label all unread newsletters as 'To Read'."

🔒 Security Note

Gmail uses OAuth 2.0. Your password is never stored — only an access token with scoped permissions. You can revoke access anytime from your Google Account settings.

3. X (Twitter) Integration

Purpose: Draft posts, publish tweets, reply to mentions, manage lists, and assist with social-media workflows.

How to Connect

  1. In your Avatar Claw, go to Integrations → X → Connect.
  2. Sign in to your X account.
  3. Authorize Avatar Claw.
  4. Approve the requested permissions.
  5. Return to Avatar Studio — the status should show Connected.

What You Can Do

  • Draft tweets and threads
  • Generate thread ideas from a topic
  • Reply to mentions automatically
  • Schedule or prepare content (depending on available features)
  • Analyse posting activity and engagement

💡 Example Prompts

  • "Draft a tweet announcing our new AI certification program."
  • "Reply to the last three mentions with a thank-you message."
  • "Create a 5-tweet thread about prompt engineering best practices."

4. WhatsApp Integration

Purpose: Connect your AI agent to WhatsApp for customer conversations, automated messaging, and support workflows.

How to Connect

  1. In your Avatar Claw, go to Integrations → WhatsApp → Connect.
  2. Follow the setup wizard.
  3. Link your WhatsApp Business account (or another supported connection method).
  4. Complete any required verification (QR code or phone number).
  5. Save the integration.

What You Can Do

  • Answer customer questions 24/7
  • Send automated replies based on keywords
  • Handle support conversations and escalate to humans
  • Provide order updates and tracking information
  • Send appointment reminders and notifications
