# IGCSE Mathematics Notes (0580)

## 1. NUMBER

### Types of Numbers

| Type | Description | Examples |
|------|-------------|----------|
| **Natural numbers** | Counting numbers | 1, 2, 3, ... |
| **Integers** | Whole numbers + negatives | ..., -2, -1, 0, 1, 2, ... |
| **Rational** | Can be written as fraction | ½, 0.75, -3 |
| **Irrational** | Cannot be written as fraction | π, √2, e |
| **Prime** | Exactly two factors | 2, 3, 5, 7, 11 |
| **Square numbers** | n² | 1, 4, 9, 16, 25 |
| **Cube numbers** | n³ | 1, 8, 27, 64 |

### Prime Factorization
- Breaking down into prime factors
- Use factor trees
- **LCM:** Multiply all prime factors (highest power of each)
- **HCF:** Multiply common prime factors (lowest power of each)

### Standard Form
```
a × 10^n where 1 ≤ a < 10
```
- Large numbers: positive n
- Small numbers: negative n

### Bounds & Accuracy
- **Upper bound:** Measurement + ½ smallest unit
- **Lower bound:** Measurement - ½ smallest unit
- Example: 5.2 cm (to 1 d.p.) → UB = 5.25, LB = 5.15

### Fractions
- Addition/subtraction: Common denominator
- Multiplication: Top × top, bottom × bottom
- Division: Flip second fraction, then multiply
- To decimal: Divide numerator by denominator
- To percentage: × 100

### Percentages
- **Increase:** New = Original × (1 + %/100)
- **Decrease:** New = Original × (1 - %/100)
- **Reverse percentage:** Original = New / (1 ± %/100)
- **Compound interest:** A = P(1 + r/100)^n
- **Simple interest:** I = PRT/100

### Ratio & Proportion
- Simplify by dividing by common factor
- Share in ratio: Add parts, divide total, multiply each part
- Map scales: 1:n means 1 cm on map = n cm in reality
- Direct proportion: y = kx
- Inverse proportion: y = k/x

## 2. ALGEBRA

### Expanding Brackets
- Single bracket: a(b + c) = ab + ac
- Double brackets (FOIL): (a + b)(c + d) = ac + ad + bc + bd
- Difference of squares: (a + b)(a - b) = a² - b²
- Perfect square: (a ± b)² = a² ± 2ab + b²

### Factorizing
- Common factor: ab + ac = a(b + c)
- Difference of squares: a² - b² = (a + b)(a - b)
- Quadratic: x² + bx + c = (x + p)(x + q) where pq = c, p+q = b
- Quadratic (ax²): Find two numbers that multiply to ac and add to b

### Solving Linear Equations
1. Expand brackets
2. Collect like terms
3. Get variable on one side
4. Divide by coefficient

### Solving Simultaneous Equations

**Elimination:**
- Multiply to make coefficients equal
- Add or subtract to eliminate one variable
- Solve for remaining variable
- Substitute back

**Substitution:**
- Rearrange one equation
- Substitute into other equation
- Solve

### Solving Quadratic Equations
1. **Factorizing:** (x + a)(x + b) = 0 → x = -a or -b
2. **Quadratic formula:**
   ```
   x = [-b ± √(b² - 4ac)] / 2a
   ```
3. **Completing the square:**
   ```
   x² + bx + c = (x + b/2)² - (b/2)² + c
   ```

### Algebraic Fractions
- Same rules as numerical fractions
- Factorize first where possible
- Cancel common factors

### Indices

| Rule | Formula |
|------|---------|
| Multiplication | a^m × a^n = a^(m+n) |
| Division | a^m ÷ a^n = a^(m-n) |
| Power of power | (a^m)^n = a^(mn) |
| Zero | a^0 = 1 |
| Negative | a^(-n) = 1/a^n |
| Fractional | a^(1/n) = n√a |

### Surds
- √a × √b = √(ab)
- √a ÷ √b = √(a/b)
- Rationalize denominator: multiply by conjugate

### Rearranging Formulas
- Treat variable you want as subject
- Use inverse operations
- Same rules as solving equations

## 3. SEQUENCES

### Types

| Type | Pattern | nth Term |
|------|---------|----------|
| **Linear** | Add/subtract same number | an + b |
| **Quadratic** | Second differences equal | an² + bn + c |
| **Geometric** | Multiply/divide same number | ar^(n-1) |

### Finding nth Term
- **Linear:** Find difference (a), then adjust to get first term (b)
- Example: 5, 8, 11, 14... Difference = 3, 3×1=3, need +2 → nth term = 3n + 2

## 4. GRAPHS

### Straight Lines
- y = mx + c
- m = gradient, c = y-intercept
- Gradient = (change in y) / (change in x)

### Parallel & Perpendicular
- Parallel: Same gradient
- Perpendicular: m₁ × m₂ = -1

### Plotting Lines
- Table of values
- Or find two points (e.g., when x=0 and y=0)

### Quadratic Graphs (Parabolas)
- y = ax² + bx + c
- U-shape if a > 0, n-shape if a < 0
- Turning point at x = -b/(2a)
- Roots where y = 0 (cross x-axis)

### Other Graphs
- **Cubic:** y = ax³ + bx² + cx + d
- **Reciprocal:** y = a/x
- **Exponential:** y = a^x

### Inequalities
- >, <, ≥, ≤
- Solve like equations
- If multiply/divide by negative: flip sign
- On number line: open circle for < >, closed for ≤ ≥
- Shading regions on graphs

### Travel Graphs
- Distance-time: Gradient = speed
- Speed-time: Gradient = acceleration, Area = distance

### Functions
- f(x) notation
- Substitute values
- Composite: fg(x) = f(g(x))
- Inverse: f^(-1)(x) — swap x and y, rearrange

## 5. GEOMETRY

### Angles

| Type | Description | Sum |
|------|-------------|-----|
| **On straight line** | Adjacent | 180° |
| **Around point** | Full turn | 360° |
| **In triangle** | Interior | 180° |
| **In quadrilateral** | Interior | 360° |
| **In polygon** | Interior | (n-2) × 180° |
| **Exterior** | One per vertex | 360° |

### Parallel Lines
- Corresponding angles: Equal (F-shape)
- Alternate angles: Equal (Z-shape)
- Allied/co-interior: Sum to 180° (C-shape)

### Circle Theorems

1. **Angle at centre = 2 × angle at circumference**
2. **Angles in same segment are equal**
3. **Angle in semicircle = 90°**
4. **Opposite angles in cyclic quadrilateral sum to 180°**
5. **Alternate segment theorem:** Angle between tangent and chord = angle in alternate segment
6. **Tangent perpendicular to radius**
7. **Tangents from external point are equal**

### Constructions
- Perpendicular bisector
- Angle bisector
- 60° angle
- Perpendicular from point to line

## 6. MENSURATION

### Perimeter & Area

| Shape | Area | Perimeter |
|-------|------|-----------|
| **Rectangle** | l × w | 2(l + w) |
| **Triangle** | ½ × b × h | Sum of sides |
| **Parallelogram** | b × h | Sum of sides |
| **Trapezium** | ½(a + b)h | Sum of sides |
| **Circle** | πr² | 2πr |
| **Sector** | (θ/360) × πr² | — |

### Surface Area & Volume

| Shape | Surface Area | Volume |
|-------|-------------|--------|
| **Cuboid** | 2(lw + lh + wh) | l × w × h |
| **Cylinder** | 2πr² + 2πrh | πr²h |
| **Cone** | πr² + πrl | ⅓πr²h |
| **Sphere** | 4πr² | 4/3 πr³ |
| **Pyramid** | Base + triangles | ⅓ × base area × h |

### Arc Length & Sector Area
```
Arc length = (θ/360) × 2πr
Sector area = (θ/360) × πr²
```

## 7. PYTHAGORAS & TRIGONOMETRY

### Pythagoras' Theorem
```
a² + b² = c²
```
- c = hypotenuse (longest side, opposite right angle)
- For right-angled triangles only

### Trigonometric Ratios (SOH CAH TOA)
```
sin θ = Opposite / Hypotenuse
cos θ = Adjacent / Hypotenuse
tan θ = Opposite / Adjacent
```

### Finding Angles
```
θ = sin⁻¹(O/H) = cos⁻¹(A/H) = tan⁻¹(O/A)
```

### 3D Trigonometry
- Find right-angled triangles within 3D shapes
- May need to find one length first, then use it

### Sine & Cosine Rules (Extended)

**Sine Rule:**
```
a/sin A = b/sin B = c/sin C
```

**Cosine Rule:**
```
a² = b² + c² - 2bc cos A
cos A = (b² + c² - a²) / 2bc
```

**Area of triangle:**
```
Area = ½ab sin C
```

### Bearings
- Measured clockwise from North
- Three figures (e.g., 045°, 270°)
- Back bearing: ± 180°

## 8. VECTORS & TRANSFORMATIONS

### Vectors
- Column vector: (x, y) or (x, y, z)
- Magnitude: √(x² + y²)
- Addition: (a, b) + (c, d) = (a+c, b+d)
- Multiplication by scalar: k(a, b) = (ka, kb)

### Transformations

| Transformation | Description | Notation |
|----------------|-------------|----------|
| **Translation** | Slide | Vector (x, y) |
| **Reflection** | Flip over line | Line of reflection |
| **Rotation** | Turn around point | Centre, angle, direction |
| **Enlargement** | Scale from point | Centre, scale factor |
| **Stretch** | Stretch from line | Invariant line, scale factor |
| **Shear** | Slide parallel to line | Invariant line, shear factor |

### Describing Transformations
- Always state all required information
- For reflection: state line
- For rotation: state centre, angle, direction
- For enlargement: state centre and scale factor

### Matrix Transformations (Extended)
- Reflection, rotation, enlargement matrices
- Combined transformations: multiply matrices

## 9. PROBABILITY

### Basic Probability
```
P(event) = Number of favourable outcomes / Total number of outcomes
```

### Rules
- P(A or B) = P(A) + P(B) - P(A and B)
- P(A and B) = P(A) × P(B|A)
- Independent: P(A and B) = P(A) × P(B)
- Mutually exclusive: P(A and B) = 0

### Tree Diagrams
- Multiply along branches
- Add different routes

### Venn Diagrams
- Union (A ∪ B): A or B or both
- Intersection (A ∩ B): A and B
- Complement (A'): Not A

## 10. STATISTICS

### Types of Data

| Type | Description |
|------|-------------|
| **Qualitative** | Descriptive (colours, opinions) |
| **Quantitative — Discrete** | Countable (shoe size, number of students) |
| **Quantitative — Continuous** | Measurable (height, weight, time) |

### Averages

| Measure | Calculation | Best Used When |
|---------|-------------|---------------|
| **Mean** | Sum of values / Number of values | No extreme values |
| **Median** | Middle value (ordered) | Extreme values present |
| **Mode** | Most frequent value | Categorical data |

### Range & Spread
- **Range:** Maximum - Minimum
- **Interquartile Range (IQR):** Q₃ - Q₁
- **Semi-IQR:** (Q₃ - Q₁) / 2

### Quartiles
- Q₁: 25th percentile
- Q₂ (Median): 50th percentile
- Q₃: 75th percentile

### Cumulative Frequency
- Running total of frequencies
- Plot: Upper boundary vs cumulative frequency
- Median: Read at 50% of total
- IQR: Read at 25% and 75%

### Histograms
- Area of bar represents frequency
- Frequency density = Frequency / Class width
- No gaps between bars (continuous data)

### Frequency Polygons
- Plot midpoints of class intervals
- Join with straight lines

### Scatter Graphs
- Show correlation between two variables
- Positive correlation: Both increase
- Negative correlation: One increases, other decreases
- No correlation: No pattern
- Line of best fit through middle of points

### Stem-and-Leaf Diagrams
- Stem = tens digit
- Leaf = units digit
- Must have key
- Ordered for easier reading

## 14. DIFFERENTIATION (EXTENDED)

### Basic Rule
```
If y = x^n, then dy/dx = nx^(n-1)
```

### Applications
- **Gradient of curve:** Value of dy/dx at point
- **Stationary points:** dy/dx = 0
- **Maximum:** Gradient changes + to -
- **Minimum:** Gradient changes - to +

### Finding Stationary Points
1. Differentiate
2. Set equal to zero
3. Solve for x
4. Find y coordinate
5. Determine nature (max/min) by checking gradient either side

## EXAM TIPS

### Calculation Questions
1. **Show working** — Method marks available
2. **Check calculator mode** — Degrees for trigonometry
3. **3 significant figures** — Unless specified otherwise
4. **Units** — Include correct units in final answer
5. **Estimate first** — Check answer is reasonable

### Algebra
1. **Expand carefully** — Watch negatives
2. **Factorize fully** — Check by expanding
3. **Quadratic formula:** Write it down first
4. **Simultaneous equations:** Label clearly

### Geometry & Mensuration
1. **Diagrams:** Draw if not given
2. **Formulas:** State formula before substituting
3. **Units:** Convert all to same unit before calculating
4. **Circles:** Use π button, not 3.14

### Graphs
1. **Label axes** — With quantity and unit
2. **Scales** — Sensible, consistent, using more than half the grid
3. **Plot accurately** — Use sharp pencil, small crosses
4. **Line of best fit** — Through middle of points, ignore outliers
5. **Read carefully** — Use graph to estimate, show construction lines

### Statistics
1. **Mean from table:** Use midpoints for grouped data
2. **Histograms:** Calculate frequency density
3. **Cumulative frequency:** Plot at upper boundary
4. **Compare distributions:** Use mean and spread (range/IQR)

### General
1. **Read question twice** — Note exact requirements
2. **Command words:**
   - **Calculate/Find/Work out:** Show working
   - **Write down:** Little or no working needed
   - **Draw:** Accurate with ruler
   - **Sketch:** General shape, label key points
   - **Describe:** Use data from question
   - **Explain:** Give reasons
   - **Show that:** Must not use answer given
3. **Check back** — Have you answered the question asked?
4. **Use time wisely** — Don't spend too long on one question

### Formula Sheet
Know what is NOT given:
- Pythagoras: a² + b² = c²
- SOH CAH TOA
- Circle theorems (statements given, but need to know which to use)
- Quadratic formula
- Sine and cosine rules
- Area of triangle = ½ab sin C
